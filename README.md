# Terus Tech

Landing page for Terus Tech, a software agency — built with React, Vite, and Tailwind CSS.

## Stack

- React 18 + TypeScript + Vite
- Tailwind CSS
- [`shaders`](https://www.npmjs.com/package/shaders) for the animated hero background
- [`lucide-react`](https://lucide.dev/) for icons

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
